Fluent C++ API

Method chaining inspired by modern Rust and Swift APIs. Build shader pipelines with zero boilerplate.

Hot Reload

Shaders reload in-place during development. Save your GLSL file, see changes instantly on screen.

GPU Profiling

Memory Safe

RAII everywhere. GPU resources are freed automatically when objects go out of scope.

SPIR-V Ready

Precompile shaders to SPIR-V for Vulkan compatibility or faster startup in production.

SFML & Raylib

Drop Shimera into existing SFML or Raylib projects without touching your windowing code.

From zero to shader in 3 lines.

Shimera's fluent API was designed so that adding a shader pipeline feels as natural as writing a function call.

▶Live typing animation — real Shimera API
main.cpp — shimera demo
01
Add the library
# With xmake
xmake require shimera

# Or CMake FetchContent
FetchContent_Declare(shimera
  GIT_REPO https://github.com/your/shimera
  GIT_TAG  v0.8.0)
02
Create a context
#include <shimera/shimera.hpp>

auto ctx = shm::Context::create({
  .width = 1280,
  .height = 720,
  .title  = "My App",
});
03
Load & run shaders
auto shader = ctx.shader()
  .vert("shaders/mesh.vert")
  .frag("shaders/pbr.frag")
  .build();

ctx.run([&](shm::Frame& f) {
  shader.bind()
    .set("u_time", f.elapsed());
  f.draw(mesh, shader);
});
